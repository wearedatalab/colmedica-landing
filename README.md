# Colmédica · Landing Planes

Landing de planes de medicina prepagada Colmédica.

## Archivos

- **`index.html`** — Landing principal con scroll vertical, todas las secciones (Hero, Planes, Quiz, Clínicas, Centros Médicos, Especialidades, Beneficios, Testimonios, PQR, CTA, Footer)
- **`plan-quiz.html`** — Quiz autocontenido "Encuentra tu plan ideal" (versión standalone)
- **`colmedica-logo-white.png`** — Logo Colmédica blanco
- **`supersalud.png`** — Logo Vigilado Supersalud para footer

## Stack

- HTML5 + CSS3 + JavaScript vanilla
- Sin dependencias (excepto Google Fonts: Red Hat Display)
- Manual de marca Colmédica respetado: paleta oficial (#0058A2, #009FE3, #E30613) y tipografía Red Hat Display
- 100% responsive (móvil, tablet, desktop)
